CMD Web — сайт загрузок

1. Распакуй CMD-Web-website.zip.
2. Открой index.html в браузере. Два небольших ZIP-архива уже лежат в downloads.
3. Большие файлы слишком велики для включения в маленький пакет сайта: скачай CMD-Web.exe и publish.zip из сообщений ChatGPT и положи их в папку downloads. EXE назови CMD-Web.exe, а исходный ZIP — Cweb-original-package.zip.
4. Для публикации загрузи всю папку CMD-Web-site на статический хостинг, сохраняя структуру папок.
5. .NET 8 SDK доступен по официальной ссылке Microsoft на странице сайта.
